--- setback found and fixed ---------------------------------------------------------------
First `ros2 run` failed with "ModuleNotFoundError: No module named 'chess'":
  * in this image, `python3` on PATH is a virtualenv (/opt/ros_python/bin/python3), so pip installed
    python-chess there;
  * ROS entry points are generated with `#!/usr/bin/python3`, which does not see that virtualenv.
Workaround used in this run:
  python3 -m pip install --target /opt/chess_deps "chess>=1.10,<2" && export PYTHONPATH=/opt/chess_deps:$PYTHONPATH
Permanent fix: setup_deps.sh now installs python-chess for /usr/bin/python3 (committed after this run;
to be re-verified in a fresh container).

Also learned: python3-chess is not packaged for Ubuntu 24.04 (pip only); Stockfish from apt lands in
/usr/games, which is not on root's PATH in the container (the node finds it there automatically).
